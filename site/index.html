A CLI for Z-Library. 终端里的 Z-Library。

Search, download, and send books to Kindle or WeRead. Or hand it to Claude Code and Codex. 搜书、下载、发送到 Kindle 或微信读书，也能交给 Claude Code 和 Codex。

$ brew install heartleo/tap/zlib-cli

Install in one line. 一行命令安装。

macOS, Linux, and Windows. zlib update keeps it current. 支持 macOS、Linux 和 Windows，之后用 zlib update 更新。

$brew install heartleo/tap/zlib-cli

macOS and Linux.macOS 和 Linux。

>winget install --id heartleo.zlib --exact

Windows.Windows。

$curl -fsSL https://raw.githubusercontent.com/heartleo/zlib/main/install.sh | sh

macOS and Linux. Installs to /usr/local/bin; may ask for sudo.macOS 和 Linux。安装到 /usr/local/bin，可能需要 sudo。

$go install github.com/heartleo/zlib/cmd/zlib@latest

Any system with Go 1.26 or later.任意系统，需要 Go 1.26 或更高版本。

$ git clone https://github.com/heartleo/zlib
$ cd zlib
$ go build -o zlib ./cmd/zlib

Any system with Go 1.26 or later.任意系统，需要 Go 1.26 或更高版本。

One app for all of it. 一个界面，用上全部功能。

zlib tui puts search, downloads, history, Kindle, WeRead and settings in one terminal app. zlib tui 把搜索、下载、历史、Kindle、微信读书和设置放进同一个终端应用。

Can’t connect? 连不上？

Run zlib doctor to list the domains that work from your network. Have your own mirror? Run zlib mirrors add <domain>. 运行 zlib doctor，列出你的网络能访问的域名。有自己的镜像？运行 zlib mirrors add <domain>。
